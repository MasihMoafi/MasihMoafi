## Selected work

- [**Elpis**](https://github.com/MasihMoafi/Elpis) — Coding-agent environment with controlled context, persistent memory, safe execution, and exact or lean session continuation.
- [**Eyes Wide Shut**](https://github.com/MasihMoafi/Eyes-Wide-Shut) — Empirical red-team study of five context- and representation-sensitive safety failure families in `gpt-oss-20b`.
- [**Voice Commander**](https://github.com/MasihMoafi/Voice-commander) — Local GPU-accelerated speech-to-text pipeline for fast voice-to-text and prompt capture.
- [**Gated Transformer FX Signals**](https://github.com/MasihMoafi/gated-transformer-fx-signals) — Research implementation comparing a gated Transformer with tree baselines for EUR/USD directional prediction, with optional MetaTrader 5 integration.
