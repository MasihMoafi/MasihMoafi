## Current flagship: Elpis

[**Elpis**](https://github.com/MasihMoafi/Elpis) is a terminal coding agent designed to preserve purpose, context, and useful memory across long tasks and new sessions.

It builds on the Codex Rust execution foundation and adds Elpis-owned retrieval, portable workspace context, durable memory, provider choice, behavior, and visual identity. The project is under active development; the first public version will be released only after its acceptance checks pass.

## Developer-experience tools

Most of my public tools began as solutions to problems in my own workflow.

- [**Voice Commander**](https://github.com/MasihMoafi/Voice-commander) — local voice transcription and optional AI refinement for turning speech into usable prompts.
- [**Skills I Use**](https://github.com/MasihMoafi/Skills-I-use) — compact, reusable operating instructions for coding agents, including first-principles engineering and documentation harnesses.
- [**Rubik's Coding Lab**](https://github.com/MasihMoafi/rubiks-coding-lab) — an interactive 3D environment for exploring cube state, permutations, and rotation logic.
- [**Eyes Wide Shut**](https://github.com/MasihMoafi/Eyes-Wide-Shut) — an AI security research project created for the OpenAI gpt-oss red-teaming challenge.

## Research and applied ML
